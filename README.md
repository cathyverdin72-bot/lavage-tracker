# Lavage Tracker

Build a mobile-first web app called "Lavage International Car Progress Tracker".

This is a vehicle progress tracking system for Lavage International, a car wash and detailing business.

For the first version, build ONLY the basic working MVP.

CUSTOMER:

- A customer can enter a unique tracking code.

- The customer can see their vehicle make/model.

- The customer can see their plate number.

- The customer can see the service being performed.

- The customer can see the current vehicle status.

- Show a visual progress timeline.

STAFF:

- A simple staff dashboard.

- Staff can create a new vehicle job.

- Fields:

  - Customer name

  - Phone number

  - Vehicle make/model

  - Plate number

  - Service

  - Current status

  - Staff notes

- Staff can update the vehicle status.

STATUS OPTIONS:

1. Car Received

2. Inspection

3. Washing

4. Detailing

5. Quality Check

6. Ready for Pickup

7. Completed

DESIGN:

- Professional and modern.

- Mobile-first and optimized for iPhone.

- Clean car-care/business appearance.

- Use "Lavage International" everywhere.

- Do NOT use placeholder business names such as "Shine & Co. Auto Spa".

- Make navigation simple.

- Use large, easy-to-tap buttons.

For now:

- Use sample data so the app can be tested immediately.

- Keep the data simple.

- Do not add payments.

- Do not add WhatsApp.

- Do not add complicated authentication.

- Do not add unnecessary features.

Make all screens and buttons functional.
